# How AES makes a decision

User Task -> Task Analyzer (deterministic) -> Context Engine (deterministic) -> Knowledge Retrieval (bounded) -> Model Router (hard policy plus soft advice) -> Learned Overlays (reversible) -> Resource Governance (hard enforcement) -> Control Engine (authority) -> Adaptive Runtime (orchestration) -> Provider (execution) -> Verification -> DecisionTrace -> Experience Miner -> Future Learning. Regression restores base policy when an overlay loses quality.
